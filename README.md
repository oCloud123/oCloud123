## 👋 Hey, I'm oCloud

I'm a developer focused on **Minecraft server development**, **Java plugins**, **backend systems**, and **automation tools**.

I enjoy building practical systems rather than just small demos — from Minecraft plugins and server infrastructure to launchers, APIs, bots and developer tools.

My main goal is creating systems that are **clean, reliable, scalable and actually useful in production**.

---

## 🚀 What I Do

- ☕ Develop **Minecraft plugins** with Java
- 🎮 Build and manage **Minecraft server systems**
- 🌐 Create **backend services, REST APIs and web systems**
- 🤖 Develop **automation tools, bots and server utilities**
- ☁️ Work on **CloudMC / oCloud projects**
- ⚡ Optimize **Minecraft performance and infrastructure**
- 🗄️ Work with **databases, caching and persistent storage**
- 🔌 Integrate plugins, APIs, proxies and external services
